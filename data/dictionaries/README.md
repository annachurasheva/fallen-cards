# Словари нормализации — копии для fallen-cards

Координата: `annachurasheva/fallen-cards` · `data/dictionaries/README.md` · v3 · 2026-10-07
Источник истины: `annachurasheva/memorial-korpech-crimea` · `data/dictionaries/` · ветка `qwen3-memorial`

## Назначение в этом репозитории

Копии словарей для downstream-слоя нормализации выхода парсера персон
(`data/processed/<имя>/<имя>-fallen.csv`, `<имя>-unclassified.csv`, схема v03 — docs/CSV_SCHEMA.md):

- `units_dict.json` — «сокращение из ЦАМО → полное название» для колонки `warunit`;
- `units_registry.json` — структура частей: parent/children, номера, даты, camo_url;
  norm-формулировки живут только в `units_dict.json`, связь через `dict_keys`;
- остальные словари источника (`ranks_dict.json`, `locations_dict.json`,
  `burials_primary.json`, `burials_current.json`) копируются сюда по мере
  подключения слоя нормализации (TASK-0014).

Парсер (`scripts/parse-obd.js`) словари НЕ читает и НЕ изменяет: сырые CSV
пишутся дословно, как пришли из ЦАМО. Нормализация — отдельный слой между
парсером и сайтом; исходные CSV неприкосновенны.

## Отличие от README источника

В `memorial-korpech-crimea` словари обслуживают конвертер `scripts/csv-to-markdown.mjs`
(сайт мемориала). В fallen-cards того скрипта нет: словари обслуживают нормализацию
выхода парсера. Форматы файлов идентичны источнику без исключений.

## Правило синхронизации

1. Правки словарей выполняются ТОЛЬКО в репозитории-источнике, по его README
   (workflow через `scripts/logs/errors.json` конвертера).
2. Перенос копии сюда — коммитом с тегом `chore: sync dictionaries <YYYY-MM-DD>`.
3. Локальные правки копий в fallen-cards запрещены: расхождение копий одновременно
   ломает нормализацию здесь и сайт в источнике.

## Нераспознанные значения в прогонах парсера

Новые сокращения `warunit`/`rank`, не найденные в словарях, фиксируются слоем
нормализации (TASK-0014) в его журнале ошибок и оформляются как предложение
к пополнению. Внесение в словари — решением Анны-Ch, вручную, в репозитории-источнике.
Автоматического пополнения словарей из fallen-cards нет.

## Правила форматов JSON (без изменений от источника)

- кодировка UTF-8;
- только двойные кавычки;
- запятая после последней пары ключ-значение не ставится;
- проверка синтаксиса перед коммитом (например, jsonlint.com);
- `locations_dict.json` вручную не заполняется: формируется внешним процессом
  и импортируется готовым файлом — не удалять при наличии.
