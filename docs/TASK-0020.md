## Правильная логика автоматического слияния

**Критерий слияния:** извлечь все числа из строки (регулярным выражением `/\d+/g`), отсортировать. Группы с одинаковым отсортированным набором чисел сливаются автоматически.

**Примеры:**

| Строка              | Числа      | Группа                       |
| ------------------- | ---------- | ---------------------------- |
| "404 сд"            | [404]      | одинокая 404                 |
| "СКФ 404 сд"        | [404]      | одинокая 404 → СЛИТЬ         |
| "скф 404 сд 44 А"   | [44, 404]  | пара 44+404 → ДРУГАЯ группа  |
| "скф 398 сд 826 сп" | [398, 826] | пара 398+826                 |
| "СКФ 826 сп 398 сд" | [398, 826] | пара 398+826 → СЛИТЬ         |
| "скф 398 сд"        | [398]      | одинокая 398 → ДРУГАЯ группа |

## Исправленное правило слияния

Группа = **(число собственного подразделения, его уровень)**. Уровень берётся из слова-типа через карту синонимов; числа родителей (армия, корпус, фронт в строке) на ключ не влияют и группу не дробят. Литералы строк сохраняются как варианты без изменений; выживает самый частый вариант, остальные получают merge_into.

Карта уровней (синонимы → уровень):

- рота: р, ср, оро, эр, автомоб. рота
- батальон/дивизион: бат., б-н, обс, осб, олбс, медбат, сапбат, оптд, озад, тб, отб
- полк: сп, п, полк, гсп, ап, гап, кап, минп, кп, тп
- бригада: тбр, брмп
- дивизия: сд, див., гсд, кд, гмд
- корпус: ск, УР
- армия: А, арм., армия
- фронт: СКФ, КрымФ, фронт

Собственное подразделение = токен низшего уровня в строке.

## Три края, где автослияние отключается (очередь оператора)

1. **Число-калибр:** «отд 76 мм ад» — 76 это миллиметры, не номер; числа перед «мм» в токены не берутся, строка уходит оператору.
2. **Два подразделения через точку с запятой:** «77 сд; 55 тбр» (Дорохин) — два токена одного низшего ранга; автослияние отключено, решение ваше.
3. **Нет слова-типа:** «скф», «КрымФ», «п/п 91060», «в/ч 15 ппс 492» — уровень не определяется; каждая строка своей группой до вашего решения.
