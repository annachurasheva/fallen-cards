### 9.2. Ручное редактирование warunits-fallen-cards.md

**Файл:** `data/dictionaries/warunits-fallen-cards.md`

**Формат таблицы:**
```markdown
| Ключ                | Развёрнутое имя                          | Написания                              | Адрес источника решений |
| ------------------- | ---------------------------------------- | -------------------------------------- | ----------------------- |
| 999-01-fallen-cards | 47-я отдельная рота охраны               | скф 47 А 47 оро                        |                         |
| 999-02-fallen-cards | Отдельный артиллерийский дивизион        | отд 76 мм ад                           |                         |
| 999-03-fallen-cards | 231-й отдельный истребительно-противотанковый дивизион | скф 231 оптд                 |                         |
```

**ВАЖНО (§1.5, A2):**
- ✅ Ключи: `999-XX-fallen-cards` (тестовые, не пересекаются с существующими)
- ✅ Развёрнутое имя: можно указать `— (оператор)` если нет источника
- ✅ Написания: **ТОЧНО как в CSV** (регистр, пробелы, сокращения)
- ✅ Адрес источника: оставить пустым для тестовых ключей

**Пример добавления:**
```markdown

| 999-02-fallen-cards | — (оператор)                             | отд 76 мм ад                           |                         |
```

### 1. Точное совпадение (без нормализаций)

**Проверка:**
```powershell

# В MD:  "скф 47 А 47 оро" (ТОЧНО ТАК ЖЕ)
# В JSON: "скф 47 А 47 оро" (ТОЧНО ТАК ЖЕ)
# В карточке: unit_raw: "скф 47 А 47 оро" (ТОЧНО ТАК ЖЕ)
```

**НЕ ДОЛЖНО БЫТЬ:**
```
❌ "СКФ 47 А 47 ОРО"  (изменён регистр)
❌ "скф 47 а 47 оро"  (изменены пробелы)
❌ "скф47А47оро"      (удалены пробелы)
```
