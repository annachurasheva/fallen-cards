Нашёл проблему. Баг в `units-report.js` (и `generate-cards.js`) — оба скрипта всё ещё читают **`units_registry.json`** (архивный файл с вложенной схемой `.units`), а не новый **`unit_keys.json`** (плоская схема).

После рефакторинга TASK-0016 файлы переименовали и схему упростили, но скрипты остались на старом пути. Поэтому `registryIndex` строится из несуществующего или пустого файла → все записи уходят в «не распознано».

---

## Промпт Дельте (TASK-0018: фикс чтения unit_keys.json)

> **Контекст:** fallen-cards, текущий HEAD. После рефакторинга TASK-0016 реестр переименован в `unit_keys.json` (плоская схема `{_operator_note, unit-...}`, без вложенного `.units`), но два скрипта остались на старом пути `units_registry.json`. Это приводит к «Распознано: 0» в отчёте и `unit_unknown_*` во всех карточках.
>
> **Задача:** заменить чтение реестра в двух скриптах. Отдача: Code Tool Record, полные файлы, без push; после файлов — три строки.
>
> **1. `scripts/units-report.js` — весь файл.** Найти блок чтения реестра:
>
> ```js
> const registryRaw = readJsonSafe(path.join(DICT_DIR, "units_registry.json"));
> const unitsRegistry = registryRaw.units || registryRaw;
> ```
>
> Заменить на:
>
> ```js
> const unitsRegistryRaw = readJsonSafe(path.join(DICT_DIR, "unit_keys.json"));
> const unitsRegistry = unitsRegistryRaw; // плоская схема, без .units
> ```
>
> Логика построения `registryIndex` не меняется (она уже работает с плоским объектом).
>
> **2. `scripts/generate-cards.js` — весь файл.** Тот же блок заменить на:
>
> ```js
> const unitsRegistryRaw = readJsonSafe(path.join(DICT_DIR, "unit_keys.json"));
> const unitsRegistry = unitsRegistryRaw;
> ```
>
> **3. Обновить документацию:**
>
> - `data/dictionaries/README.md` — убрать упоминания `units_registry.json`, описать `unit_keys.json` как основной реестр ключей (плоская схема: `_operator_note` + записи `unit-<ключ>` с полями `dict_keys`, `type`, `number`, `parent`, `history_note`).
> - `docs/ARCHITECTURE.md` — то же.
>
> **Критерий приёмки:**
>
> 1. `node scripts/units-report.js` показывает «Распознано: ≥ 100» (соответствует coverage из issue #1).
> 2. `node scripts/generate-cards.js --dry-run` не выдаёт `unit_unknown_*` для записей с известными ключами (например, `404 сд` → `unit-404-sd`, а не `unit_unknown_<hash>`).
> 3. `git grep -n "units_registry\.json"` пустой (старый файл нигде не упоминается).
>
> **Запрещено:** трогать логику назначения ключей (`assignUnitKey`, `assignLocationKey`, `assignBurialKey`), парсер CSV, остальные словари.
>
> **Тег:** `fix: scripts — units-report и generate-cards читают unit_keys.json (вместо архивного units_registry.json)`
