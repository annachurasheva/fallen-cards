## 2. Почему консоль молчит (и почему «пробный прогон выглядел живым»)

В `run-edge-obd.ps1` дренаж stderr написан как `while ($proc.StandardError.Peek() -ge 0)`. `Peek()` на пустом перенаправленном потоке **блокирует навсегда**. Последовательность: первая строка stdout выведена → уходим в дренаж stderr → Peek встаёт намертво → ни сторож, ни дальнейшие строки не работают. В пробном прогоне весь вывод выпал **одним залпом** в момент завершения node (когда stderr закрылся) — «живость» была иллюзией; штампы в строках — время node, а не время вывода. В длинном прогоне залпа можно ждать часами.

Это отдельный дефект лаунчера — в TASK-0007.

## 2. Git: причина и ремонт

Причина: вы amend-или `c0f2eae` → `24825b2` (правка сообщения). GitHub приняли force-обновление, а **sourcecraft остался со старым c0f2eae**. Ваш `git pull sourcecraft develop` попытался влить этот устаревший дубль в локальную ветку → незавершённый merge (MERGE_HEAD). Push отклонён, потому что локальная ветка не содержит c0f2eae.

Ремонт (sourcecraft — зеркало, его история здесь производная):

```
git merge --abort
# если откажется из-за грязного дерева: git stash push -u -m "bad-run" ; git merge --abort ; git stash drop
git fetch sourcecraft
git log --oneline develop..sourcecraft/develop    # ожидание: только c0f2eae (docs: update)
git diff c0f2eae 24825b2 --stat                    # ожидание: пусто (amend тронул только сообщение)
git push --force-with-lease sourcecraft develop
```

Пустой diff на шаге 4 — страховка: он доказывает, что на sourcecraft нет ничего, чего нет у вас содержательно. После пуша оба зеркала снова равны.

Правило на будущее: amend допустим только до первого push в любой remote; после push — только новый коммит, либо синхронный force во все зеркала в той же сессии.
