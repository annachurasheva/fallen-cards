# CSV_SCHEMA.md — схема выходных CSV парсера OBD Memorial (v03)

База: TASK-0006/0007. Утверждённый список колонок ниже является окончательным;
любые новые колонки добавляются только через новую задачу с явным решением.

## Кодировка и формат

- UTF-8 **без BOM**;
- разделитель — запятая, значения с запятой/кавычками/переводами строк экранируются кавычками;
- первая строка файла — заголовок (имена колонок через запятую).

## Правила для читателей

- Сопоставление колонок — **по именам, не по позициям**; позиции могут смещаться только через явное решение.
- `_allParams` — служебное поле экстрактора, в CSV **не сериализуется**.
- Пустое значение поля = пустая строка в CSV (не `null`, не `N/A`).
- Классификация файлов: `<имя>-fallen.csv` (статус «убит»/«погиб»), `<имя>-unclassified.csv` (остальное), `<имя>-error.csv` (технические ошибки, отдельная схема: `document_id,primary_url,error_type,error_message,Дата`).
