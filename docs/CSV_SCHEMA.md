# CSV_SCHEMA.md — схема выходных CSV парсера OBD Memorial (v03)

Версия схемы: **v03** (задача TASK-0006).
Кодировка всех файлов: **UTF-8 без BOM**.

## Правила для читателей

1. Сопоставление значений — **по именам колонок, а не по позициям**:
   читатели обязаны читать первую строку-заголовок и искать колонки по именам.
2. Имена колонок фиксирует `HEADERS` в `src/parsers/obd-memorial/extractors.js`.
3. Поле `rebural_from` **зафиксировано с опечаткой** (правильное написание —
   `reburial_from`). Исправление запрещено: все потребители используют
   именно это имя. Опечатка — фактическое имя колонки в схеме.
4. Пустая строка в колонке означает «данные отсутствуют в источнике».
   Парсер ничего не выдумывает: пишутся только данные документа.

## Файлы, использующие схему

- `data/processed/<имя>/<имя>-fallen.csv` — записи `cause_of_death` со «убит»/«погиб»;
- `data/processed/<имя>/<имя>-unclassified.csv` — все прочие статусы, включая пустой.

Оба файла содержат заголовок из 24 имён колонок в порядке `HEADERS`.
