### 3. Подключить `burials_primary.json` и `burials_current.json`

**Проблема:** Словари мест захоронений пустые, нужно наполнять из прогона парсера.

**Решение:** Нормализатор собирает уникальные значения `primary_burial` и `current_burial` и пишет в словари.

**Промпт кодеру:**

> **Контекст:** fallen-cards, commit a3457a3. Ничего не запускать. Результат — Code Tool Record.
>
> **Задача:** Наполнить словари `burials_primary.json` и `burials_current.json` из прогона парсера.
>
> **Изменение 1.** Файл `src/normalizers/location.js` — добавить функции сбора уникальных мест:
>
> ```javascript
> /**
>  * Собирает уникальные места захоронений из массива карточек.
>  *
>  * @param {Array} cards — массив нормализованных карточек
>  * @returns {Object} { primary: { ... }, current: { ... } }
>  */
> export function collectBurials(cards) {
>   const primary = {};
>   const current = {};
>
>   for (const card of cards) {
>     const p = card.burial?.primary_norm;
>     const c = card.burial?.current_norm;
>
>     if (p && !primary[p]) {
>       primary[p] = {
>         name: p,
>         count: 1,
>         first_seen: card.person?.death_date || null,
>       };
>     } else if (p) {
>       primary[p].count++;
>     }
>
>     if (c && !current[c]) {
>       current[c] = {
>         name: c,
>         count: 1,
>         first_seen: card.person?.death_date || null,
>       };
>     } else if (c) {
>       current[c].count++;
>     }
>   }
>
>   return { primary, current };
> }
> ```
>
> **Изменение 2.** Файл `scripts/normalize.js` — после нормализации всех карточек, вызвать `collectBurials` и записать словари:
>
> ```javascript
> import { collectBurials } from "../src/normalizers/location.js";
> import { writeFileSync } from "node:fs";
> import { join } from "node:path";
>
> // ... после нормализации всех карточек ...
>
> // Сбор уникальных мест захоронений
> const burials = collectBurials(normalizedCards);
>
> // Запись словарей
> const primaryPath = join(ROOT, "data/dictionaries/burials_primary.json");
> const currentPath = join(ROOT, "data/dictionaries/burials_current.json");
>
> writeFileSync(primaryPath, JSON.stringify(burials.primary, null, 2));
> writeFileSync(currentPath, JSON.stringify(burials.current, null, 2));
>
> console.log(
>   `💾 Словари мест захоронений: primary=${Object.keys(burials.primary).length}, current=${Object.keys(burials.current).length}`,
> );
> ```
>
> **Изменение 3.** README.md — добавить раздел про словари:
>
> ````markdown
> ### Словари мест захоронений
>
> После нормализации автоматически обновляются словари:
>
> - `data/dictionaries/burials_primary.json` — уникальные места первичного захоронения
> - `data/dictionaries/burials_current.json` — уникальные места текущего захоронения
>
> Каждый словарь содержит:
>
> ```json
> {
>   "с. Корпечь, Ленинский р-н, Крым": {
>     "name": "с. Корпечь, Ленинский р-н, Крым",
>     "count": 15,
>     "first_seen": "1942-03-12"
>   }
> }
> ```
> ````
>
> ```
>
> **Самопроверка (без запуска):**
> - `location.js` содержит `collectBurials`
> - `normalize.js` импортирует `collectBurials` и записывает словари
> - README.md обновлён
> - Коммиты не сделаны
>
> **Формат:** Code Tool Record трёх файлов + три строки: Изменено / Проверено / Не тронуто.
> ```

**После применения:** запуск `node scripts/normalize.js` после парсинга наполнит словари уникальными местами с количеством карточек и первой датой.

## Порядок действий

1. Примените три промта кодеру (можно одним сообщением, кодер разделит задачи).
2. После коммита перезапустите Edge: `.\tools\run-edge-obd.ps1` — окно не откроется.
3. Запустите полный прогон: `node scripts/parse-obd.js --input=obd_primary_urls_2026-09-22-22-37-31.txt` — лог будет тихим.
4. Запустите нормализацию: `node scripts/normalize.js` — словари `burials_primary/current.json` наполнятся.

Пришлите хвост лога после полного прогона и содержимое `burials_primary.json` (первые 10 записей) — сверю географию и пойдём к сравнению с плитами.
