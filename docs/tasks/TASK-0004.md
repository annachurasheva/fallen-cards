## Как откатиться безопасно (данные не теряем)

Полный `reset --hard` сбросит и коммиты данных (`31f38a7`, `3468d46` — результаты прогонов), а они ценные и досмысловые. Поэтому — выборочно:

```powershell
# код — в состояние до нормализации
git checkout 9b1b768 -- scripts/normalize.js src/normalizers/location.js

# артефакты нормализации — удалить
Remove-Item data\dictionaries\burials_primary.json, data\dictionaries\burials_current.json, data\dictionaries\settlements.json -ErrorAction SilentlyContinue
Remove-Item data\processed\*__normalized.json -Recurse -ErrorAction SilentlyContinue
Remove-Item data\processed\*__skipped.txt -Recurse -ErrorAction SilentlyContinue

# точка зафиксирована навсегда
git tag pre-normalization 9b1b768

git status
```

После этого `normalize.js` снова заглушка, `location.js` без collectBurials/attachObject, карточки и CSV прогонов — на месте, нетронутые.
