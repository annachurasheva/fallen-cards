## Вход

- data/processed/<session>/ — CSV из obd (уже распарсены)
- data/raw/pmn_hand_01/pamyat_parsed_rfc4180.csv — pmn-данные (те же document_id)

## Обогащение

Для каждой строки obd-CSV:

1. Поиск в pmn по document_id
2. Если найдено:
   - place_birth: если пусто в obd, взять из pmn
   - conscription_location: если пусто в obd, взять из pmn
   - notes: конкатенация obd.notes + pmn.notes (разделитель `; `)
   - date_death: если obd пустое, взять из pmn (с модификатором "не позднее")
   - source: добавить `pmn` в список источников
3. Запись обогащённой строки в `data/processed-enriched/<session>/`
